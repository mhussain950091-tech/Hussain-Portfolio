            Read project details

            Synthora AI is a synthetic data generation platform developed during the HackDataV2 hackathon. Real-world datasets are often scarce, sensitive, or restricted by privacy requirements, which slows development, testing, and analytics. Synthora AI addresses this by generating realistic artificial data that preserves the structure and relationships of real datasets, without exposing confidential information.

            My Role

            As Team Lead, I directed the project from planning through delivery. I coordinated the team, assigned responsibilities, and kept the work aligned with the hackathon timeline. I also owned the platform’s entire database workflow.

            Key Contributions

            Database architecture: Designed the data model and controlled how data moves through the platform. Relational integrity: Defined primary key and foreign key (PK-FK) relationships so that generated data stays consistent and valid across linked tables. Multi-format data flow: Managed the flow of tabular, relational, and document-based data, so the platform can handle both structured and semi-structured data. Frontend delivery: Built the user interface and deployed it on Vercel, making the platform accessible through a live web application. Team coordination: Worked with the backend developer to integrate the database layer, backend services, and interface into a single working product.

            Technical Focus

            Database design, PK-FK relationship modeling, relational and document data handling, synthetic data generation, and web deployment (Vercel).

            Outcome

            Delivered a working, deployed prototype within the hackathon timeframe, demonstrating a practical approach to privacy-safe data generation.

            Read project details

            NovaSight is an AI-powered dashboard creation platform that turns raw CSV data into interactive, presentation-ready dashboards in minutes. It removes the need for manual charting and BI tool expertise, so non-technical users can explore and understand their data on their own.

            My Role

            As Project Lead, I led a team of five, from planning and task distribution to integration and delivery. I also contributed to the platform’s data and database design.

            Key Features

            CSV to dashboard: Users upload a raw CSV file, and the platform builds a dashboard automatically. Smart chart recommendations: Suggests suitable chart types based on the structure and content of the data. KPI cards: Highlights key metrics at a glance. Interactive filters: Sidebar filters let users explore the data dynamically. Export: Dashboards and results can be exported for reporting and sharing. AI integration: Integrates the Anthropic Claude API and Gemini API to add intelligence to the analysis workflow. Synthetic Data module (in development): A schema-builder interface for generating tabular, relational, and document datasets.

            Technology Stack

            Python, Streamlit, MySQL, Plotly, Anthropic Claude API, Gemini API.

            Impact

            NovaSight makes data analysis accessible to people without technical or BI backgrounds, cutting the time from raw data to usable insight.

            Hotel Management System

            Hotel teams need connected records for guests, rooms, bookings, and billing.

            I contributed relational database design and application logic for a Java Swing and MySQL hotel management system.

            • Java Swing
            • JDBC
            • MySQL

            Impact Centralized hotel records and booking workflows; [add metric: records managed or time saved].

            Read project details

            The Hotel Management System is a database-driven application that manages the daily operations of a hotel in one place. It replaces manual registers and scattered records with a structured system for guest registration, room allocation, bookings, check-in and check-out, and billing.

            The system keeps room availability up to date, prevents double bookings, and stores every guest record and transaction in a relational database. This gives hotel staff accurate information and reduces errors in daily work.

            My role: I worked on the project as part of a team, contributing to the database design and the system’s core logic, including the relationships between guests, rooms, bookings, and billing.
